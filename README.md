
# 💻 Portfólio Pessoal | Ruan Pablo

Bem-vindo ao meu portfólio pessoal! Este projeto está sendo desenvolvido com o objetivo de apresentar minha trajetória na programação, minhas habilidades técnicas e os projetos que venho desenvolvendo durante meus estudos.

O portfólio reúne informações sobre mim, meus conhecimentos em desenvolvimento web e programação, além de links para meus projetos e repositórios no GitHub.

A proposta é construir uma presença profissional na área de tecnologia, documentar minha evolução como desenvolvedor e compartilhar meus aprendizados por meio de projetos práticos.

---

## 📌 Sobre o Projeto

Este portfólio é um site pessoal desenvolvido utilizando **HTML5 e CSS3**, com foco em organização, responsividade, acessibilidade e design moderno.

A interface foi planejada para oferecer uma navegação simples e intuitiva, permitindo que visitantes conheçam meu perfil, explorem meus projetos e visualizem as tecnologias com as quais estou trabalhando.

O projeto também representa uma oportunidade de aplicar conhecimentos de desenvolvimento web na prática, desde a estruturação semântica do HTML até a estilização dos componentes com CSS.

### Objetivos

- Apresentar meu perfil e meus objetivos na área de tecnologia.
- Organizar e divulgar meus projetos de programação.
- Demonstrar meus conhecimentos em HTML5 e CSS3.
- Compartilhar minha evolução nos estudos de Python.
- Desenvolver um projeto pessoal para meu portfólio profissional.
- Praticar a criação de interfaces responsivas.
- Aplicar boas práticas de organização e manutenção de código.
- Facilitar o acesso aos meus repositórios no GitHub.

## 🛠️ Tecnologias Utilizadas

### HTML5

O HTML5 é utilizado para estruturar o conteúdo do site e organizar suas diferentes seções.

Entre os recursos utilizados estão:

- Elementos semânticos para melhorar a organização do documento.

- Bordas, sombras e outros detalhes visuais.
- Media queries para adaptação a diferentes telas.
- Rolagem suave entre as seções.
- Estados de foco para melhorar a navegação por teclado.

## 📂 Estrutura do Projeto

A estrutura básica dos arquivos é organizada da seguinte maneira:

```text
portfolio/
├── index.html
├── style.css
└── README.md
```

### Descrição dos arquivos

**`index.html`**

Arquivo principal do projeto. Contém a estrutura da página, a navbar, a apresentação pessoal, a seção de projetos, as habilidades e o rodapé.

**`style.css`**

Arquivo responsável pela aparência visual do site, incluindo cores, tipografia, espaçamentos, layouts, efeitos visuais e adaptações para dispositivos móveis.

**`README.md`**

Documento que apresenta o projeto, explica suas tecnologias, descreve sua estrutura e fornece instruções para execução e personalização.

## ⚙️ Como Executar o Projeto

Como o projeto utiliza apenas HTML5 e CSS3, não é necessário instalar dependências, configurar um servidor ou utilizar ferramentas de compilação.

### Pré-requisitos

- Um navegador atualizado, como Google Chrome, Microsoft Edge ou Mozilla Firefox.
- Um editor de código, como Visual Studio Code, caso queira modificar os arquivos.
- Git, opcionalmente, para clonar o repositório.

### 1. Clone o repositório

Abra o terminal e execute:

```bash
git clone URL_DO_SEU_REPOSITORIO
```

Substitua `URL_DO_SEU_REPOSITORIO` pelo endereço real do repositório.

### 2. Acesse a pasta do projeto

```bash
cd portfolio
```

Caso o nome da pasta seja diferente, utilize o nome correspondente.

### 3. Abra o projeto

Abra a pasta no Visual Studio Code:

```bash
code .
```

Se o comando não estiver disponível, abra o VS Code manualmente e selecione a pasta do projeto.

### 4. Execute o site

Localize o arquivo `index.html` e abra-o no navegador.

Também é possível utilizar a extensão Live Server do Visual Studio Code para visualizar as alterações durante o desenvolvimento.

Não é necessário executar comandos como `npm install` ou `npm run dev`, pois o projeto não depende de Node.js ou de um framework.

## ✏️ Como Personalizar

### Alterar os textos

Abra o arquivo `index.html` e localize a seção que deseja modificar.

Você pode atualizar:

- A apresentação pessoal.
- As descrições dos projetos.
- Os nomes das habilidades.
- Os textos dos botões.
- As informações do rodapé.

### Alterar as cores

Abra o arquivo `style.css` e procure pelas propriedades de cor, como:

```css
background-color: #0b0f19;
color: #ffffff;
```

Substitua os valores pelos códigos das cores desejadas.

Se o projeto utilizar variáveis CSS, centralize as cores em um bloco `:root` para facilitar futuras alterações.

### Adicionar um novo projeto

Para adicionar um projeto:

1. Localize a seção de projetos no arquivo `index.html`.
2. Copie a estrutura HTML de um card existente.
3. Altere o título e a descrição.
4. Atualize as tecnologias utilizadas.
5. Insira o endereço real do repositório.
6. Salve o arquivo e confira o resultado no navegador.

Mantenha a mesma estrutura de classes CSS para preservar a consistência visual entre os cards.

### Atualizar as habilidades

Adicione ou remova os itens correspondentes na seção Skills, mantendo apenas tecnologias e ferramentas que façam parte dos seus estudos ou da sua experiência prática.

## ♿ Acessibilidade e Boas Práticas

Durante o desenvolvimento, alguns princípios importantes devem ser considerados:

- Utilizar HTML semântico.
- Manter uma hierarquia adequada de títulos.
- Garantir contraste suficiente entre texto e fundo.
- Utilizar descrições claras nos links.
- Manter indicadores de foco visíveis.
- Permitir navegação por teclado.
- Evitar animações excessivas.
- Respeitar a preferência do usuário por movimento reduzido.
- Manter o código organizado e legível.
- Evitar dependências desnecessárias.

Essas práticas ajudam a tornar o site mais acessível, compreensível e fácil de manter.

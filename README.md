## 🛠️ Tecnologias Utilizadas

### HTML5

O HTML5 é utilizado para estruturar o conteúdo do site e organizar suas diferentes seções.

Entre os recursos utilizados estão:

- Elementos semânticos para melhorar a organização do documento.
- Links internos para navegação entre as seções.
- Estruturação de títulos, parágrafos e listas.
- Organização dos cards de projetos e habilidades.
- Integração do arquivo CSS externo.
- Links para páginas e repositórios externos.

### CSS3

O CSS3 é responsável por toda a apresentação visual do portfólio.

Seus principais recursos incluem:

- Estilização de cores, fontes e textos.
- Layouts utilizando Flexbox e CSS Grid.
- Organização de espaçamentos e alinhamentos.
- Criação de cards para projetos e habilidades.
- Efeitos de hover e transições.
- Bordas, sombras e outros detalhes visuais.
- Media queries para adaptação a diferentes telas.
- Rolagem suave entre as seções.
- Estados de foco para melhorar a navegação por teclado.

### Tecnologias e ferramentas

| Tecnologia | Finalidade |
|---|---|
| HTML5 | Estrutura e organização do conteúdo |
| CSS3 | Estilização e responsividade |
| Git | Controle de versão |
| GitHub | Hospedagem do código e gerenciamento do repositório |
| Visual Studio Code | Ambiente de desenvolvimento |

**Observação:** o projeto utiliza somente HTML5 e CSS3 em sua implementação, sem dependência de JavaScript ou frameworks.

## 🧭 Seções do Portfólio

### 1. Início

A seção inicial apresenta meu nome, área de interesse e uma breve descrição dos meus estudos em programação.

Ela também disponibiliza um atalho para acessar os projetos.

O objetivo é permitir que os visitantes entendam rapidamente quem sou e quais são meus interesses na área de tecnologia.

### 2. Projetos

A seção de projetos reúne aplicações e exercícios desenvolvidos durante meus estudos.

Cada projeto pode ser apresentado em um card contendo:

- Nome do projeto.
- Descrição de suas funcionalidades.
- Tecnologias utilizadas.
- Link para o repositório correspondente.

Os cards apresentam projetos e exercícios feitos durante meus estudos.

### 3. Skills

A seção de habilidades apresenta as tecnologias e ferramentas com as quais estou trabalhando.

Entre elas estão HTML5, CSS3, Python, Git, GitHub e Visual Studio Code.

Os conhecimentos são apresentados de maneira transparente, diferenciando as tecnologias que já utilizei daquelas que ainda estou estudando.

### 4. Rodapé

O rodapé contém a identificação do portfólio.

## 📱 Responsividade

O portfólio foi planejado para funcionar em diferentes tamanhos de tela, incluindo computadores, tablets e smartphones.

Para isso, são utilizadas técnicas de CSS responsivo, como:

- Media queries para ajustar o layout.
- Flexbox e CSS Grid para organizar os componentes.
- Larguras flexíveis para aproveitar o espaço disponível.
- Ajustes de espaçamento e tipografia em telas menores.
- Adaptação dos cards para diferentes resoluções.
- Navegação acessível em dispositivos móveis.

O objetivo é manter uma experiência de navegação consistente, independentemente do dispositivo utilizado.

---

## 🎨 Identidade Visual

O design segue uma proposta moderna e minimalista, inspirada em interfaces utilizadas por desenvolvedores e profissionais da área de tecnologia.

As principais características visuais incluem:

- Tema escuro.
- Fundo em tons de preto ou azul-escuro.
- Cores de destaque em azul ou violeta.
- Tipografia legível.
- Cards com bordas sutis e cantos arredondados.
- Transições suaves.
- Efeitos visuais discretos.
- Organização clara das informações.

A prioridade é equilibrar aparência e funcionalidade, evitando elementos desnecessários que possam prejudicar a leitura ou a navegação.
